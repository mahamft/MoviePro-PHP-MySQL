# MoviePro Feature Matrix

| Area | Included |
|---|---|
| Authentication | Registration, login, logout, role sessions, active-account check, CSRF |
| Profile | Avatar, personal details, preferences, completion, password change, activity |
| Movies | Catalogue, filters, details, trailers, cast, ratings, reviews, upcoming titles |
| Cinemas | Venues, cities, screen seat configuration, active/inactive control |
| Shows | Dates, times, movie/cinema assignment, Gold/Platinum/Box prices |
| Seats | Live map, manual selection, automatic best seats, reservation holds |
| Cart | Timed reservation, multiple shows, child/adult types, removal, extension |
| Add-ons | Snacks, drinks, combos, stock checks and grouped order items |
| Checkout | Coupons, loyalty, fees, tax, four demo payment methods, idempotency |
| Tickets | Booking reference, QR, print styles, invoice, grouped success page |
| Customer account | Booking history, cancellation, notifications, loyalty balance |
| Admin | Movies, cinemas, shows, orders, bookings, reservations, users, reviews |
| Commerce admin | Coupons, concessions, stock, configurable fees/tax/loyalty |
| Analytics | Revenue, payment split, top movies, order and operational statistics |
| Experience | 3D cards, animated global background, cursor, transitions, responsive UI |
| PWA | Manifest, installable shell and static-asset cache |
