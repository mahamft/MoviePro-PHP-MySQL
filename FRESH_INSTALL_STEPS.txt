MOVIEPRO PHP + MYSQL — FRESH XAMPP INSTALLATION

1. Back up any existing moviepro_db database.
2. Extract this folder into C:\xampp\htdocs\
3. Start Apache and MySQL.
4. Open http://localhost/phpmyadmin
5. Click Import.
6. Import database/00_FRESH_INSTALL_FROM_SCRATCH.sql
7. Do NOT import any other SQL file for a fresh setup.
8. Open http://localhost/MoviePro_PHP_MySQL_Complete/
9. Login with the admin account below. You will be redirected to:
   http://localhost/MoviePro_PHP_MySQL_Complete/admin/index.php
